# Первый парсер договоров

Парсер реализует первый измеримый эксперимент проекта. Он читает 20 синтетических PDF и DOCX, извлекает номер, дату, заказчика, исполнителя и сумму, затем сравнивает результат с эталонной разметкой.

## Запуск

```bash
pip install -r parser_requirements.txt
python baseline_parser.py
```

Результат проверки сохраняется в `baseline_results.csv`. В терминале выводится точность отдельно по каждому полю и доля документов, в которых правильно найдены все пять значений.

## Что реализовано

- получение текста из DOCX через `python-docx`;
- получение текста из PDF с текстовым слоем через `pypdf`;
- поддержка числовых и словесных дат;
- несколько шаблонов записи номера договора;
- четыре варианта записи сторон договора;
- нормализация суммы до целого количества рублей;
- автоматическое сравнение с `ground_truth.json`.

## Ограничения

Парсер настроен на шаблоны первой версии синтетического датасета. Результат на реальных договорах может быть ниже. PDF-сканы без текстового слоя пока не поддерживаются. Следующий этап — добавить реальные обезличенные примеры, расширить правила и отдельно оценить качество на документах, которые не использовались при разработке выражений.
