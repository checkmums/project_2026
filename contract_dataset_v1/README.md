# Синтетический датасет договоров версия 1

Набор подготовлен для первого эксперимента по автоматическому извлечению реквизитов из договоров. Он содержит 20 вымышленных документов: 10 DOCX и 10 PDF.

## Состав

- `documents/` — файлы договоров;
- `labels.xlsx` — разметка для просмотра и проверки;
- `labels.csv` — та же разметка для Python;
- `labels.jsonl` — одна JSON-запись на документ;
- `ground_truth.json` — полный эталонный набор полей;
- `schema.sql` — предлагаемая структура SQLite;
- `architecture.md` и `architecture.svg` — архитектура первой версии.

## Поля разметки

- идентификатор и имя файла;
- формат документа;
- тип, номер и дата договора;
- заказчик и исполнитель;
- сумма в рублях;
- вариант шаблона и условная сложность.

## Варианты документов

- `T1` — реквизиты указаны отдельными строками;
- `T2` — стороны и номер находятся в связном вводном абзаце;
- `T3` — часть реквизитов находится в таблице;
- `T4` — реквизиты расположены в другом порядке, сумма находится внутри пункта договора.

Все названия организаций, ФИО и реквизиты являются вымышленными. Документы предназначены только для учебного проекта и не имеют юридической силы.

## Как использовать

1. Получить текст из документа.
2. Извлечь номер, дату, стороны и сумму.
3. Сравнить результат со строкой разметки по `filename`.
4. Посчитать долю правильно найденных значений отдельно для каждого поля.
