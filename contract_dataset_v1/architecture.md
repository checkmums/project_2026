# Архитектура решения

## Первая версия

На первом этапе система может быть обычным Python-скриптом или Jupyter Notebook. Пользователь указывает файл, программа извлекает текст, ищет четыре атрибута и записывает результат в CSV. Отдельный backend и база данных для первого эксперимента не требуются.

```text
PDF или DOCX
      |
      v
Извлечение текста
  pypdf / python-docx
      |
      v
Нормализация текста
пробелы, переносы, знаки
      |
      v
Извлечение атрибутов
RegEx, позднее Natasha
      |
      v
Проверка результата
сравнение с разметкой
      |
      v
CSV, позднее SQLite
```

## Извлекаемые поля

1. Номер договора.
2. Дата заключения.
3. Заказчик и исполнитель.
4. Сумма договора в рублях.

## Возможное развитие

- добавить OCR для PDF-сканов;
- использовать Natasha для распознавания организаций и ФИО;
- добавить ручное исправление найденных значений;
- хранить документы и результаты в SQLite;
- сделать простой интерфейс в Streamlit;
- оценивать качество по каждому полю на размеченном датасете.

Файл `architecture.svg` содержит эту схему в виде изображения для отчета или презентации.
